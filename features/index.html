全部功能

从共享一个目录，到管理多台存储设备。具体功能取决于存储端、访问端和系统版本。

存储与文件连接与协议共享与权限备份与恢复媒体与阅读存储端维护

存储与文件

  • 存储设备。Android 和 Mac 可选定目录并开启共享。访问端可保留多台已配对的存储设备，并切换当前目录和上传目标。
  • 文件浏览。列表、媒体网格、缩略图、排序、收藏与最近访问。可搜索当前目录，兼容版本还可搜索有权限的子目录。
  • 文件管理。上传、下载、新建目录、重命名、移动、删除和批量操作。标签、备注和批量改名工具的可用性取决于版本。
  • 导入本机文件。发现已授权目录里的视频、照片、音乐、漫画、书籍、文档和归档，核对后加入上传队列。

连接与协议

  • 局域网 HTTPS。在同一网络配对和访问。Mac 支持 Wi-Fi 和有线连接，并可在地址变化后重新发现。
  • 跨网访问。兼容的存储端和客户端可通过 Iroh 尝试直连，必要时使用中继。文件页与传输任务会显示连接方式。
  • 进阶组网。兼容配置下可使用 WebRTC、自部署信令、Tailscale 或 ZeroTier 等现有组网，并查看链路延迟和吞吐。
  • 开放协议。在存储端启用网页门户或 WebDAV。支持的客户端可在浏览器浏览和传输文件，也可用文件管理器挂载。OPDS 阅读器可连接兼容的书库。

共享与权限

  • 设备配对。扫码或复制配对码，在存储端核对并批准。可逐台撤销，也可停止整个目录的共享。
  • 目录及成员授权。共享目录默认只读，可为指定设备或家庭成员分配目录及读写权限。
  • 访客分享。支持版本可生成带有效期和提取码的临时外链。兼容场景还支持下载次数限制、二维码及访客上传。
  • 私密内容。私人书库和私密媒体目录可设单独的设备访问权限。锁定和系统验证方式随平台而异。

传输、备份与恢复

  • 大文件上传。持久上传队列、分片校验、暂停与续传、完整文件 SHA-256 校验。两端兼容时支持 4 GiB 以上文件，实际大小取决于剩余空间和文件系统。
  • 相册备份。手动选图备份，兼容版本可配置定时备份。照片按内容去重，并保存在选定的写入位置。
  • 误删恢复。回收站支持找回到原路径，带快照的版本可恢复。兼容版本可配置配额和存储端通知。
  • 外部备份。支持 S3、rclone HTTPS WebDAV 和已授权的可移除卷。切换设备时可迁移配置，目录权限须在新设备上重新授权。

媒体与阅读

  • 电影与剧集。在原目录串流播放，支持 NFO、本地海报、元数据匹配、观看进度与连续播放。兼容版本提供 DLNA、离线缓存和 Android 低码流预生成。
  • 相册。时间轴、网格、幻灯片、EXIF 信息和筛选。支持的客户端还可发现相似照片，或查看设备本地的人物与宠物分组。
  • 音乐、有声书与播客。专辑聚合、队列、LRC 歌词、倍速、书签、睡眠定时和 RSS 播客。
  • 漫画。CBZ、ZIP 和图片目录阅读，含双页、方向、护眼滤镜和进度。兼容设备可导入授权的漫画导出目录。
  • 电子书与文档。EPUB、TXT、Markdown、CSV、PDF。支持的格式可显示目录、搜索正文及保存阅读进度。
  • 电视端。Android TV 和 Apple TV 在同一局域网获准后，可浏览、播放和续播授权媒体。

存储端维护

  • 运行状态。查看后台服务、系统资源、热状态及挂载卷。存储分析可查看文件分布、大文件和重复候选。
  • Android 电池保护。兼容设备可使用系统限充、Shizuku、Root 控充或已有的 ACC，也可接入 Home Assistant 与 ESPHome 智能插座。旁路供电和控充能力取决于设备。
  • Docker 实验室。在兼容的 Android Root 或 MagicDesk Shroot 环境接入现有 Docker Engine，查看容器、端口与日志，并管理 Compose 项目。
  • 后台与外观。Android 提供后台诊断与 OLED 值守屏。Mac 可从菜单栏管理共享，并在登录后恢复后台服务。兼容客户端提供简体中文、繁体中文和英文。
