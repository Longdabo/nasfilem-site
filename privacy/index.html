隐私说明

本页介绍官网的访问方式，以及 NASFileM 的核心配对和文件连接行为。

访问官网和提交反馈

官网由 GitHub Pages 托管，页面没有账号、提交表单或分析脚本。GitHub 可能为提供服务而处理访问请求。通过 GitHub Issues 提交的内容会公开展示。请在提交前移除配对码、地址和文件内容。

查看 GitHub 隐私声明

共享目录和配对

你在存储端选择要共享的文件夹，并批准可以访问它的设备。文件保存在你选择的位置。启用照片备份时，客户端需要读取相册，并将选定内容传到你指定的存储端。

可以在存储端的已配对设备列表中撤销访问，或停止共享整个目录。撤销权限会结束后续访问，设备上已有的副本需要在该设备上管理。

文件如何传输

同一局域网内优先直连。使用跨网访问时，客户端先尝试建立直接连接。根据网络和连接设置，可能使用信令或中继服务协助连接或转发。
